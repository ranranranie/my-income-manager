# My Income Manager

Manager Series income tracking app.

This repository stores My Income Manager independently from My Budget Manager and My Asset Manager.

## Development policy

- Local device storage first; no account, server storage, cloud sync, or financial institution connection in v1.
- Work on feature branches. Do not merge to `main` without explicit approval.
- GitHub Actions are intentionally not used during the current usage-limit period.
- Never report unexecuted CI or local checks as passing.
